Publishing Spelling Dictation on Google Play

Internal testing: only you (and people you add) can install it. About 15 minutes in Play Console. Keep this page open next to Play Console. Every answer is ready to copy.

0 What you need

  • Spelling-Dictation-1.9.aab: the app file for Google Play.
  • The privacy policy link:
https://github.com/muhamedym/Assignment/blob/claude/festive-dirac-w0xyzh/PRIVACY-POLICY.md
  • The store images (icon, feature graphic, 5 phone screenshots) from the Play-Store-Images ZIP.
  • The signing key ZIP you saved earlier. It's already inside the .aab as your upload key; keep it safe for future updates.

1 Create the app

  1. Open play.google.com/console on your computer → Create app.
  2. App name:
Spelling Dictation
  1. Default language: English (United States) · App or game: App · Free or paid: Free.
  2. Tick the two declarations → Create app.

2 Add yourself as a tester

  1. Test and release → Testing → Internal testing → tab Testers → Create email list.
  2. List name: Me. Add the Gmail address your phone's Play Store uses → Save changes. Make sure the list is ticked.
  3. Under How testers join your test, copy the Join on the web link. You'll need it in step 6.

3 Upload the app

  1. Still in Internal testing → Create new release.
  2. If asked about app signing: choose Use Google-generated key (recommended).
  3. Drag Spelling-Dictation-1.9.aab into App bundles and wait until it finishes processing.
  4. Release name: 1.9. Release notes:
<en-US>
First version: spelling dictation, verb forms practice, sounds of American English, woman or man voice.
</en-US>
  1. Next → Save. If Play shows warnings only (yellow), you can continue. Leave this page open; you'll press Start rollout after step 5.

5 Store listing

Left menu: Grow users → Store presence → Main store listing. Play may ask for this before the first release.

App name

Spelling Dictation

Short description (77 of 80 characters)

Hear a word, type it, and learn its spelling, meaning, sounds and verb forms.

Full description

Spelling Dictation helps you spell English words correctly, the way you need to in exams such as IELTS. You hear a word, type it and submit. The word is never shown before you answer.

After every answer you see:
• the correct spelling, with your mistakes marked letter by letter
• the meaning, part of speech, word family and an example sentence
• American pronunciation (IPA), syllables, and silent and double letters
• for verbs: base form, past tense, past participle, -ing form and he/she/it, with the spelling rule (stopped, occurred, studied)

WHAT YOU CAN PRACTICE
• 547 built-in words: listening topics (bookings, dates, numbers, travel), 378 high-frequency listening words, and academic reading and writing vocabulary
• Verb forms: about 160 irregular verbs (go → went → gone) and verbs with spelling changes
• Your own words: type a word, and its meaning, example and pronunciation are filled in for you
• Previously missed words, until you get them right twice

LISTEN AND LEARN
• Choose a woman's or a man's voice
• Repeat the word, hear it slowly, or hear it in a sentence
• Sounds: all 41 sounds of American English, with recordings, pictures of the mouth and "test your ear" games

PRIVATE
• No account, no ads, no tracking
• Works offline. Your progress stays on your phone, and you can export a backup file at any time

6 Start the test and install

  1. Go back to Internal testing → your release → Review release → Start rollout to Internal testing.
  2. On your phone, open the Join on the web link from step 2, signed in with the same Gmail → Accept invite → Download it on Google Play → Install.
  3. It's usually available within minutes, sometimes up to a few hours. Auto Blocker won't stop it, because it comes from Google Play.

Making it public (Production) needs more: for newer personal accounts, a closed test with at least 12 testers for 14 days, then a review. Internal testing has no waiting period.

? If something goes wrong

  • "Version code 2 has already been used": each new upload needs a higher version code. Ask for a new build.
  • "Your app must target API level 36": this .aab already targets Android 16 (API 36).
  • "Package name already exists": ask for a build with a different package name (it's com.muhamedym.spellingdictation).
  • Remove the older app first if you installed a test APK on the same phone. It has a different package name, so both could appear.
