How it works

  1. Choose a mode and click Start. Each word is read twice. It is never shown or spelled out before you answer.
  2. Type the word and press Enter. Capital letters and extra spaces don't matter. Letters and endings do.
  3. If you're right, the next word starts automatically (you can turn this off).
  4. If you're wrong, you'll see your answer and the correct spelling with the differences marked. Type the correct spelling and press Enter to continue. It still counts as incorrect.
  5. At the end you see your score and can retest the words you missed. Retests are scored separately.

Where your data is saved

Everything is stored in this browser's local storage on this PC, inside your Windows user profile. Nothing is sent to any server and no account is needed.

  • Moving the app folder: in Edge and Chrome, saved progress normally stays available, because the browser stores data for all local files together. Export a backup before moving anyway, just to be safe.
  • Changing browser, Windows user or PC: the new browser starts empty. Use Progress → Export, then Import in the new browser.
  • Clearing browsing data ("Cookies and other site data") or using InPrivate/Incognito windows deletes or doesn't keep progress.

About the voices

Voices marked local are installed in Windows and work offline. Voices marked online (for example the "Natural" voices in Edge) send the word being spoken to Microsoft's or Google's speech service and need internet. No other data is sent. Your vocabulary lists and results are never sent.

No US English voice? Open Windows Settings → Time & language → Speech → Manage voices → Add voices, add English (United States), then close and reopen the browser.
